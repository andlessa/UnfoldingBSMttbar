# FeynRules Model Files

FeynRules implementations of the three top-philic models studied in this project, plus the SM files and restriction files they depend on. From these files we generate the UFO models ([../UFO_Models](../UFO_Models)) used by MadGraph and the FeynArts models ([../FA_models](../FA_models)) used by FeynArts/FeynCalc.

## Files

| File | Description |
|------|-------------|
| [Scalar.fr](./Scalar.fr) | **Scalar** model: colored scalar top partner $\varphi_T$ (`ST`, PDG 5000002) and Majorana dark fermion $\chi$ (`chi`, PDG 5000012). |
| [VLF.fr](./VLF.fr) | **VLF** model: colored vector-like fermion top partner $\psi_T$ (`psiT`, PDG 5000006) and real singlet scalar $\phi$ (`SDM`, PDG 5000022). |
| [Zprime.fr](./Zprime.fr) | **$Z^\prime$** model: spin-one mediator $Z^\prime$ (`Y1`, PDG 5000001), based on the `DMsimp_s_spin1` model. |
| [SMS-stop.fr](./SMS-stop.fr) | Earlier version of the scalar top partner model (stop + dark fermion). |
| [SMS-stop-SMQCD-NLO.nlo](./SMS-stop-SMQCD-NLO.nlo), [SMS-stop-SMQCD-NLO_CT.nlo](./SMS-stop-SMQCD-NLO_CT.nlo) | Counterterms and $R_2$ vertices generated by NLOCT for the NLO (loop) version of the stop model. |
| [SM.fr](./SM.fr) | Full Standard Model file. |
| [SMQCD.fr](./SMQCD.fr) | Simplified SM file containing only QCD and the quarks. |
| [LorentzTadpole.gen](./LorentzTadpole.gen) | FeynArts generic model file (Lorentz formalism with a tadpole vertex), needed for NLO calculations with NLOCT. |
| [DiagonalCKM.rst](./DiagonalCKM.rst) | Restriction file: diagonal CKM matrix. |
| [Massless.rst](./Massless.rst) | Restriction file: massless light quarks and leptons (only $t$, $b$ and $\tau$ are massive). |
| [NoDMHiggsCoupling.rst](./NoDMHiggsCoupling.rst) | Restriction file: removes the dark matter–Higgs portal coupling (`lamHs -> 0`). |

## Models

All new states are odd under a $\mathcal{Z}_2$ symmetry in the Scalar and VLF models, so they couple to the SM only in pairs and contribute to $t\bar{t}$ production through loops. The $Z^\prime$ contributes at tree level.

### Scalar

A colored scalar top partner $\varphi_T$ and a Majorana dark fermion $\chi$, coupled to the right-handed top:

```math
\mathcal{L}_{\mathrm{Scalar}} =
\bar{\chi}\left( i \not{\partial} - \frac{1}{2} m_{\chi} \right) \chi
+ |D_\mu \varphi_T|^2
- m_{\varphi}^2 |\varphi_T|^2
- \left( y_{\mathrm{DM}}\, \varphi_T^\dagger\, \bar{\chi} \, t_R + \text{h.c.} \right)
```

### Vector-like fermion (VLF)

A colored vector-like fermion $\psi_T$ and a real singlet scalar $\phi$, coupled to the right-handed top:

```math
\mathcal{L}_{\mathrm{VLF}} =
\bar{\psi}_T \left( i \gamma^\mu D_\mu - m_{\psi} \right) \psi_T
+ \frac{1}{2}(\partial_\mu \phi)^2
- \frac{1}{2} m_{\phi}^2 \phi^2
- \left( y_{\mathrm{DM}}\, \bar{\psi}_T \, t_R\, \phi + \text{h.c.} \right)
```

### $Z^\prime$

A spin-one mediator with vector couplings $g_q$ to the first two quark generations and $g_t$ to the top quark:

```math
\mathcal{L}_{Z^\prime} =
-\frac{1}{4} Z^\prime_{\mu\nu} Z^{\prime\mu\nu}
- \frac{1}{2} m_{Z^\prime}^2 Z^\prime_\mu Z^{\prime\mu}
- g_q Z^{\prime\mu} \sum_{i=1}^{2}\left(\bar{u}_i \gamma_\mu u_i + \bar{d}_i \gamma_\mu d_i\right)
- g_t Z^{\prime\mu} \bar{t} \gamma_\mu t
```

In [Zprime.fr](./Zprime.fr), $g_q$ and $g_t$ correspond to the vector couplings `gVu11`, `gVu22`, `gVd11`, `gVd22` and `gVu33`.

## Parameter names

| Symbol | Scalar.fr | VLF.fr | Zprime.fr |
|--------|-----------|--------|-----------|
| top-partner mass | $m_\varphi$ = `mST` | $m_\psi$ = `mPsiT` | – |
| dark-state mass | $m_\chi$ = `mChi` | $m_\phi$ = `mSDM` | – |
| coupling | $y_{\mathrm{DM}}$ = `yDM` | $y_{\mathrm{DM}}$ = `yDM` | $g_q$, $g_t$ |
| mediator mass | – | – | $m_{Z^\prime}$ = `MY1` |
