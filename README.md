# Unfolding BSM @ ttbar
Repository for holding code and data for the BSM ttbar project

## Folders and files

Below we describe the folders stored in this repository. 



 ---
 * [Cards](./Cards): stores cards used in each model. 
 * [DiscriminantTTBAR_ScalarAsimov](./DiscriminantTTBAR_ScalarAsimov.ipynb): Notebook holding the results for the asimov significance of the universe where the Scalar is the true model. Also holds plots of the kinematical distributions.
 * [helpers](./helpers.py): Holds the majority of the functions used in the analysis contained in the python notebooks. 
 * [Recast/Zprime](./Recast/Zprime): stores limits of resonant searches for a Z prime boson. 
 * [UFO_Models](./UFO_Models): stores UFO for each model. 
 ---
