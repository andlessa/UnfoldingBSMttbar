# FeynArts Models

FeynArts model files generated by FeynRules (`WriteFeynArtsOutput`) from [../feynrules_models](../feynrules_models), using the notebooks in [../mathematicaNBs/loadModels](../mathematicaNBs/loadModels).

| Folder | Description |
|--------|-------------|
| [Scalar-FA](./Scalar-FA) | Scalar model, tree level. |
| [Scalar_NLO-FA](./Scalar_NLO-FA) | Scalar model with the NLOCT counterterms and $R_2$ vertices (`.nlo`). |
| [VLF-FA](./VLF-FA) | VLF model, tree level. |
| [VLF_NLO-FA](./VLF_NLO-FA) | VLF model with counterterms and $R_2$ vertices (`VLF_NLO_CT.nlo`). |
| [Zprime-FA](./Zprime-FA) | $Z^\prime$ model. |

Each folder contains the model file (`.mod`) and the parameter file (`.pars`). Pass them to FeynArts with the `Model ->` option of `InsertFields`.

The NLO models use the generic model [../feynrules_models/LorentzTadpole.gen](../feynrules_models/LorentzTadpole.gen).
